# FoxTales Roadmap

Small, independently reviewable pull requests. Items depending on TBD values in GAME_SPEC.md wait for decisions.

1. Project foundation: documentation and configuration (this PR).
2. Angular scaffold under `frontend/` and frontend CI.
3. ASP.NET Core scaffold: `FoxTales.Api` and `FoxTales.Api.Tests`, plus backend CI.
4. PostgreSQL and EF Core: `Infrastructure` folder, first migration.
5. Bingo card generation in `Domain`, with backend tests.
6. Ball draw engine without duplicates.
7. Win detection: rows, columns, diagonals.
8. Bingo board UI in Angular.
9. Standard 45-ball round flow.
10. Second Chance.
11. Backend-issued guest sessions.
12. Save player progress and inventory.
13. Coin economy (requires TBD decisions).
14. Helpers: Time Freeze, Lucky Daubs, extra coins, mystery box, instant win (requires TBD decisions).
15. Book adventure: 30 levels, clues and visual elements, served without exposing hidden answers.
16. Book guess, validated on the backend.
17. Prize wheel at level 15.
18. Mystery-box rewards at level 30.
19. Fox animations and woodland theme.
20. Deployment: GitHub Pages, Render, Neon.
21. Optional registration and guest progress transfer.
22. Additional games and book themes.
