# FoxTales Design References

Approved visual direction for FoxTales Bingo. Future sessions should follow these images for layout, palette, woodland atmosphere and fox character style.

- `bingo-reference-night.jpg`: night woodland, wooden panels, peeking foxes above the cards, current-ball panel, recent calls, wooden toolbar.
- `bingo-reference-autumn.jpg`: autumn woodland, ball row on top, peeking foxes, leaf daubs, wooden floor controls.

Rules:

- References are visual direction only. Do not use them as UI backgrounds or ship them in the app.
- Cards, balls, buttons and counters are real Angular elements.
- Artwork (foxes, lanterns, foliage) lives in separate files under `frontend/public/art/` so it can be animated independently.
- Current artwork is placeholder and will be replaced by original FoxTales illustrations.
- Do not copy third-party game graphics or branding.
